## Running the app — Windows PowerShell gotcha

- `environment.sh` is bash-only. Running `./environment.sh` in PowerShell sets
  nothing, and even in bash it runs in a **subshell** so exports never reach the
  parent shell. Symptom: `npm run dev` starts Vite fine (port 5173) but the API
  dies with `DATABASE_URL must be set` — a half-up stack that looks healthy.
- Fix: created `environment.ps1` (PowerShell twin of `environment.sh`, gitignored).
  Must be **dot-sourced**: `. .\environment.ps1` then `npm run dev`.
- Script only applies defaults when a variable is unset, so external overrides win.
- Guarded the closing `node --version` lookup with `Get-Command -ErrorAction
  SilentlyContinue` so sourcing never fails when node is absent from PATH
  (it is missing in some isolated tool sessions; only an npm shim resolves).
- If PowerShell blocks scripts: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
- Docs updated: `docs/devenv.md` gained a "Running the app" section;
  `docs/design/sourcemap.md` lists `environment.ps1`.

## Port 3000 is squatted by Open WebUI (env hazard)

- On this machine port 3000 is owned by **Open WebUI** (uvicorn/FastAPI via
  `com.docker.backend.exe` + `wslrelay.exe`), not by @mou/api. Symptom: Vite
  starts on 5173 and the stack looks healthy, but `POST /api/auth/login`
  returns **405 `{"detail":"Method Not Allowed"}`** with header
  `server: uvicorn`, and `GET /api/zones` returns Open WebUI's SPA HTML with
  200 — so Playwright's readiness probe can even be fooled into passing.
- `@mou/api` reads `process.env.PORT` (default 3000) and silently dies with
  EADDRINUSE; `node --watch` then just waits for file changes.
- Workaround: run the API on 3001 and point the web at it:
  `$env:PORT=3001; $env:VITE_API_URL="http://localhost:3001"; npm run dev`
- Added `PORT` and `VITE_API_URL` to `turbo.json` `globalEnv` (forwarding only,
  no default value, so the Playwright suite still pins API_PORT=3000).
- Do NOT set a `PORT` default in `environment.ps1` / `environment.sh`: the
  Playwright config hardcodes `API_PORT = 3000`, so a global override would
  desync the tests from the servers.
